Your Anthropic API key

The key goes to the docxkeun chat server running on this computer, which checks it, keeps it in memory and makes the Claude calls to api.anthropic.com. Your browser does not store it.

The server forgets the key when it stops. To skip this step, start it with ANTHROPIC_API_KEY set. Create a key at console.anthropic.com.

The server is using the key from ANTHROPIC_API_KEY. A key entered here replaces it until the server restarts.
